# Cooking Blog — Start

A broken recipe blog. Your job is to make it work and make it pretty.

## 1. Run it

```bash
npm install
npm run dev
```

This **automatically opens two browser tabs**:

- `http://localhost:5173/` → the app you're fixing
- `http://localhost:51204/__vitest__/` → a visual test dashboard (auto-reruns on save)

Keep both tabs open the whole time.

## 2. Read your mission

👉 **[STEPS.md](./STEPS.md)** — 6 goals in order. Tick them as you go.

## When something breaks

Open the browser console (F12). The app will throw red errors that name the exact file and line you need to fix. **Read them.**

## Other scripts

- `npm run dev:app` — only the app, no tests
- `npm run test` — tests in the terminal
- `npm run build` — production build (no need to use this in class)
